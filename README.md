# Carrito_comprasPK

A learning project where I develop a dynamic shopping cart built with HTML5, CSS3, and Vanilla JavaScript.  
This project includes product listing, category-based filtering, and a fully functional cart with persistent data storage using localstorage.


🛠️Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap Icons


✅Features
- Product catalog with images  
- Category filtering (Autos, Motos, Camiones)  
- Add and remove items from the cart  
- Persistent cart using localstorage  
- Dynamic price calculation  
- Empty cart & purchase confirmation actions  
- Responsive layout
